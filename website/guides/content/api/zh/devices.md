# 设备与名称

TianShanOS 的接口既能管理控制器自身，也能控制与它连接的计算机。调用前先确定目标对象，避免把一种状态当成另一种状态。

| 用户名称 | API 中常见标识 | 你会用它做什么 |
| --- | --- | --- |
| 管理控制器 | `system.*` | 查询 TianShanOS 版本、内存和任务，重启管理服务所在的控制器 |
| 推理计算机 | `device: "agx"` | 查询电源状态、开关机、复位；算力遥测通过 `monitor.*` 读取 |
| 应用计算机 | `device: "lpmu"` | 查询电源状态、开关机、复位，以及配置上层网络接入 |
| 散热风扇 | `fan.*`，数值 `id` | 查看 RPM、设置控制模式、温度曲线和输出范围 |
| 触摸区灯光、板载灯光、矩阵屏 | `touch`、`board`、`matrix` | 灯光显示、动画、矩阵图片、二维码或文字 |
| 本地存储 | `/sdcard/...` 等路径 | 文件管理、配置包和受支持的升级素材 |
| 远端主机 | SSH 主机配置中的 `id`、`host` | 登录服务器执行命令或管理后台服务；不必就是本机内置计算机 |

`agx`、`lpmu` 是接口使用的稳定标识，本稿在说明中使用“推理计算机”“应用计算机”。例如控制应用计算机时仍须传 `"device":"lpmu"`。

## 常见读数怎么理解

- **风扇占空比 duty**：控制输出的百分比，范围 0–100。实际转速用 `rpm` 表示。占空比未知时 `duty` 可以为 `null`，同时看 `duty_valid`。
- **温度源**：温度可能来自本地传感器、算力监控、用户变量或手动测试值。看 `source`、`valid` 和时间信息，再决定是否使用读数。
- **电源良好 power_good**：被控设备的硬件电源状态指示。它不能证明操作系统或推理服务已经就绪。
- **USB 目标 target**：选择 USB 复用通道的连接对象。切换可能影响正在使用该 USB 路径的连接。
- **运行记录 run_id**：标识一次远端受管服务运行。记录保留不代表进程此刻仍在运行；需要读取并核验状态。
- **异步操作回执**：包含操作编号与结果查询凭据。保留整份回执，用来继续查结果，不能只保存一个显示名称。

## 三层完成状态

1. 接口接受了请求，例如返回 `started:true`。
2. 对应设备动作或远端进程达到目标状态。
3. 你的业务服务就绪，例如 HTTP 健康检查通过或应用输出了就绪标记。

按任务确认到所需的层级。管理控制器重启、计算机上电、远端应用启动分别使用不同操作。
