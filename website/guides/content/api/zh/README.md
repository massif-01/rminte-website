# TianshanOS API 使用手册

用脚本或自己的系统查看设备、控制计算机、接收实时状态、执行远端任务，并维护配置与升级。你需要了解 HTTP、JSON 和基本服务器运维，无需了解设备的电路或固件内部结构。

本手册基于 **TianshanOS 0.6.4** 编写。

## 接入顺序

第一次先读快速接入，完成一次只读查询。接着选一个与你的任务对应的场景；场景中包含操作顺序、请求、结果判断与失败处理，可以独立照做。需要更多参数时再打开接口参考。

除明确列出的默认账户admin/root及初始密码rm01外，示例中的地址、文件名、Token与响应值用于演示。请求应使用你管理设备的实际地址和当前密码；示例不包含私人Token、已修改的密码或真实业务记录。

## 内容范围

全量参考按28个功能分组覆盖277个注册名称，分别列出路径、允许方法、最低权限、参数、示例与结果判断；其中config.pack.apply保留名称但不支持实际应用。文件上传下载、镜像直传和WebSocket另有专页。

首次接入可运行[只读示例](examples/README.md)。
