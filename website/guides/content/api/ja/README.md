# TianshanOS API 使用ガイド

独自のスクリプトやシステムから、機器の監視、コンピューターの制御、リアルタイムの状態受信、リモートタスクの実行、設定や更新の管理を行うためのガイドです。HTTP、JSON、基本的なサーバー運用の知識を前提とします。回路やファームウェア内部の知識は必要ありません。

このガイドは **TianshanOS 0.6.4** に基づいています。

## 読み進め方

まずクイックスタートで読み取り専用のリクエストを試します。次に目的の操作例に進み、結果の確認と問題が起きた場合の復旧手順まで確認してください。個々のパラメーターを調べるときは API リファレンスを参照します。

ここに記載した admin/root と初期パスワード rm01 は製品の初期設定です。それ以外のアドレス、ファイル名、トークン、応答値は説明用の例です。管理対象機器の実際のアドレスと現在のパスワードを使用してください。非公開のトークン、変更済みのパスワード、実際の業務データは例に含まれていません。

リファレンスは、28 の機能グループに属する 277 個の登録名を収録しています。config.pack.apply も含まれますが、この名前は互換性のために残されており、汎用設定の適用には使えません。ファイル・イメージ転送専用のルートと WebSocket メッセージは、それぞれ別の章で説明します。登録名が存在していても、必要なハードウェア、ストレージ、認証情報、リモートサービスが利用可能とは限りません。
