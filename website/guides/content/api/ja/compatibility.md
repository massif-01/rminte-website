# バージョンと互換性

このガイドは **TianshanOS 0.6.4** に基づいています。後のバージョンでも、インターフェースや手順が変わっていなければ参考にできます。パラメーターや結果が異なる場合は、実際に使用しているバージョンの説明に従ってください。

## 接続とアカウント

| 項目 | 説明 |
| --- | --- |
| 管理 API | HTTP、デフォルトのポート 80、プレフィックス /api/v1。例えば http://10.10.99.97 |
| リアルタイムメッセージ | WebSocket, ws://device-address/ws |
| デフォルトアカウント | admin/root、どちらも最初は rm01。変更された場合は現在のパスワードを使用する |
| セッション認証 | Authorization: Bearer にログイントークンを指定します |
| アクセス制御 | 各 API の最低ロールに加え、リソース、バージョン、所有者に応じた確認を行います |

## 機能の前提条件

API が存在していても、実行に必要な機能やリソースがすべて利用可能とは限りません。呼び出す前に、関連する状態を確認してください。

| 機能 | 前提条件 |
| --- | --- |
| 温度、ファン、電源、コンピューター | 初期化されたドライバー、既存のターゲット、有効な測定値 |
| 計算リソースのテレメトリ | 実行中のモニター、到達可能なホスト サービス、最新の有効なデータ |
| ファイルと SD アップデート | 必要なストレージがマウントされており、ファイルが存在し、十分な容量があります。直接アップロードには別のフローがあります |
| SSH/SFTP と管理対象サービス | ネットワーク、認証情報、ホストのフィンガープリント、キー、保存済みの設定、タスク容量 |
| 自動化 | 設定が読み込まれて有効になっていること、エンジンの状態と参照先が有効であること、書き込み時のバージョンが一致すること |
| 設定パッケージ | 機器・受信先の識別情報と発行元の信頼設定。エクスポートには Developer 機能も必要です |
| デバイス PKI とアップデート | 診断には有効な PKI 資料と正しい時刻が必要です。更新には機器に対応する完全な APP/WWW イメージが必要です |
| マトリックスの内容 | 対応する表示先と、利用可能なフォント・画像ファイル |

## エイリアスとサポートされていないエントリ

config.pack.apply は登録名が残されていますが、汎用設定の適用には使えません。対象オブジェクト専用のインポート API を使用します。led.set は指定範囲のピクセルに書き込みます。ota.upload_begin/end/abort はアップロードを制御しますが、データを送るための公開 upload_write API はありません。通常の連携では、イメージ全体を送信するバイナリアップロードを使用してください。

OTA は、upgrade_url/start_url および upgrade_file/start_file エイリアスを保持します。新しい統合には start_url/start_file を優先します。

## mTLS 診断サービス

このサービスは証明書で認証する独立した診断サービスで、既定のポートは 443 です。/api/v1 を別のポートで提供するものではありません。利用可否は PKI 資料、設定、サービスの状態に依存します。Bearer トークンはクライアント証明書の代わりにはなりません。

| メソッド／パス | 必要な証明書ロール | 目的 |
| --- | --- | --- |
| GET / | anonymous（匿名） | 稼働状態 |
| GET /api/auth/whoami | viewer | 証明書の識別情報 |
| GET /api/test/viewer | viewer | 読み取りロールテスト |
| GET /api/test/operator | operator | オペレーター役割テスト |
| GET /api/test/admin | admin | 管理者の読み取りテスト |
| POST /api/test/admin-action | admin | 管理者による書き込みテスト |

これらの API は、状態、接続先の身元、権限を診断するためのもので、機器の管理操作を実行するものではありません。証明書の viewer/operator/admin と、管理 API の READ/ADMIN/ROOT は別の認証体系に属するため、相互に置き換えることはできません。
