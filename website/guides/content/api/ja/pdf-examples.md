# 付属のサンプル

PDF には read_status.py と subscribe.js が添付されています。添付ファイルに対応した PDF リーダーで保存してください。編集可能な資料にも同じファイルが含まれています。例のアドレス、トークン、証明書のパスは、実際の機器の設定ではありません。

## コード例をコピーする

コード ボックスには、コードに行番号が混合されていない選択可能なテキストが含まれています。インデントと行末を正確に保持するには、右上隅にあるクリップを使用して名前付きソース ファイルを保存するか、PDF リーダーの添付パネルから保存します。

リーダーが添付ファイルをサポートしていない場合、ダウンロード パッケージには、一致するファイル名を持つ code-examples/en 内のすべてのオリジナルのサンプルが含まれています。 API リクエスト JSON を、対応するエンドポイントの request.json として保存します。応答の例と WebSocket メッセージは、その章で説明されている目的を果たします。使用する前に、アドレス、トークン、その他のプレースホルダーを入力します。

## Python 読み取り専用クエリ

Python 3 とその標準ライブラリで十分です。デバイスのアドレスを使用して次を実行します。

```sh
python3 read_status.py --base 'http://10.10.99.97' \
  --user admin
```

コマンド履歴ではなく、非表示のプロンプトにパスワードを入力します。スクリプトはログインし、ステータスを読み取り、ログアウトを試みます。ハードウェアの制御、リモート タスクの実行、またはアップグレードは行いません。リダイレクトは行われず、自動再試行も実行されません。出力内の valid/duty_valid およびその他の測定フラグを確認します。

## ブラウザのサブスクリプション

subscribe.js は、サードパーティ ライブラリを使用せずに watchTianShan を ES モジュールとしてエクスポートします。デバイスにアクセスできるブラウザを使用してください。まず HTTP ログインを通じてトークンを取得します。

```javascript
import {watchTianShan} from './subscribe.js';
const close = watchTianShan({
  baseUrl: 'http://10.10.99.97',
  token: yourLoginToken,
  onData: message => renderYourDashboard(message.data),
  onState: state => showConnectionState(state)
});
```

renderYourDashboard/showConnectionState は、組み込む画面側で用意します。画面を離れるときは close() を呼び出してください。切断後は認証と購読を復元するまで、データが古いことを表示します。トークンをソースコード、URL、通常のログへ記録してはいけません。この例は、自動再接続や操作の再実行を行いません。
