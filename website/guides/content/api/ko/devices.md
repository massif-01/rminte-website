# 장치와 명칭

TianshanOS는 컨트롤러와 연결된 컴퓨터를 모두 관리합니다. API를 호출하기 전에 대상을 식별하십시오. 상태 값은 다양한 사항을 설명합니다.

| 사용자 표시 이름 | API 식별자 | 목적 |
| --- | --- | --- |
| 관리 컨트롤러 | system.* | TianshanOS 버전, 메모리, 작업 및 컨트롤러 다시 시작 |
| 추론 컴퓨터 | device:"agx" | 전원 상태, 전원 제어 및 재설정; monitor.*는 컴퓨팅 원격 측정을 제공합니다. |
| 애플리케이션 컴퓨터 | device:"lpmu" | 전원 상태, 전원 제어, 재설정 및 상위 네트워크 액세스 설정 |
| 냉각 팬 | fan.* and numeric id | RPM, 제어 모드, 온도 곡선 및 출력 제한 |
| 터치 조명, 보드 조명, 매트릭스 디스플레이 | touch, board, matrix | 색상, 효과, 이미지, QR 코드 및 텍스트 |
| 로컬 저장소 | /sdcard/... and other supported paths | 파일, 구성 패키지 및 지원되는 업데이트 자료 |
| 원격 호스트 | Saved SSH host id/host | 서버 명령 또는 관리 프로세스; 반드시 내장된 컴퓨터 중 하나일 필요는 없습니다. |

agx 및 lpmu를 API 식별자로 정확하게 사용하세요. 예를 들어, 애플리케이션 컴퓨터는 여전히 `{"device":"lpmu"}` 로 주소가 지정됩니다.

## 측정값을 올바르게 해석

- **팬 듀티비**는 0~100 범위의 출력 비율입니다. RPM은 회전 속도입니다. 듀티비를 확인할 수 없으면 null일 수 있으므로 duty_valid도 확인하세요.
- **온도 소스**는 로컬 센서, 컴퓨팅 원격 측정, 변수 또는 수동 테스트 값일 수 있습니다. 소스, 유효한 플래그, 타임스탬프를 확인하세요.
- **power_good**은 하드웨어 전원 표시입니다. 운영 체제나 애플리케이션이 준비되었는지 여부는 확인되지 않습니다.
- **USB 대상**은 공유 USB 경로를 선택합니다. 이를 전환하면 이전 경로의 트래픽이 중단될 수 있습니다.
- **run_id**는 관리형 원격 서비스 실행을 식별합니다. 보유된 레코드는 해당 프로세스가 아직 실행 중인지 확인하지 않습니다. 상태를 확인하세요.
- **작업 접수 정보**에는 작업 식별자와 결과 자격 증명이 포함됩니다. 표시 이름만이 아닌 전체 작업 접수 정보를 보존하세요.

## 완료 확인의 세 단계

1. API는 예를 들어 start:true를 반환하여 요청을 수락합니다.
2. 장치 작업 또는 원격 프로세스가 요청된 상태에 도달합니다.
3. 상태 확인을 통과하는 등의 방법으로 애플리케이션이 준비됩니다.

작업에 필요한 단계를 확인하세요. 컨트롤러를 다시 시작하고, 컴퓨터에 전원을 공급하고, 애플리케이션을 시작하는 것은 별도의 작업입니다.
