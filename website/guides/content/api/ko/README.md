# TianshanOS API 사용 가이드

자체 스크립트와 시스템을 연결하여 장치를 모니터링하고, 컴퓨터를 제어하고, 실시간 상태를 수신하고, 원격 작업을 실행하고, 구성 및 업데이트를 유지 관리합니다. 이 가이드에서는 HTTP, JSON 및 기본 서버 작업에 익숙하다고 가정합니다. 회로 및 펌웨어 지식이 필요하지 않습니다.

이 가이드는 **TianshanOS 0.6.4**를 기반으로 합니다.

## 읽기 순서

먼저 빠른 시작에서 읽기 전용 요청을 완료하세요. 그런 다음 결과 확인 및 복구 단계를 포함하여 작업에 대한 시나리오를 따르십시오. 개별 매개변수가 필요한 경우 참조를 엽니다.

문서화된 기본 계정 admin/root 및 초기 비밀번호 rm01은 제품 기본값입니다. 기타 주소, 파일 이름, 토큰 및 응답 값은 예시입니다. 관리하는 기기의 실제 주소와 현재 비밀번호를 사용하세요. 예시에는 개인 토큰, 변경된 비밀번호 또는 실제 애플리케이션 기록이 포함되어 있지 않습니다.

인터페이스 참고 문서는 28개 기능 그룹의 등록 이름 277개를 다룹니다. 이름만 유지되고 일반 설정 적용은 지원하지 않는 config.pack.apply도 포함됩니다. 파일·이미지 전용 경로와 WebSocket 메시지는 별도 장에서 설명합니다. 이름이 등록되어 있어도 필요한 하드웨어, 저장소, 인증 정보 또는 원격 서비스가 준비되었다는 뜻은 아닙니다.
