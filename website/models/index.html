RMQ 系列模型

分析，直抵专业深处。推理，释放硬件潜能。

RMQ3x 与 RMQ4 是 RMinte 面向高专业度场景打造的模型系列，覆盖法律、调查、安全治理、前沿科研与社会研究。它们打通领域知识、深度推理与工具调用，让 Agent 从厘清问题、确立判断走向持续行动，直接交付严谨的文书、代码与研究成果。

推理引擎

专用引擎，释放模型全部潜能。

RMQ3x 与 RMQ4 现已全面运行于 RMinte 自研 C++ 及 Rust 推理引擎与深度定制 vLLM。紧贴模型架构与 RM-01 硬件特性，我们从底层重构算子、执行路径与运行时，让卓越的模型能力，扎实落地为极速流畅的推理体验。

自研 C++ 及 Rust 推理引擎

极低运行开销，更高执行效率。

RMinte 自研 C++ 及 Rust 引擎极其轻量，Runner 自身常驻内存仅约 2 MB（不含模型权重、KV Cache 与上下文）。同等模型、精度与量化配置下，无论是输入处理（prefill）还是逐 token 生成（decode），性能均领先于我们深度优化后的 vLLM 实现。

贴合硬件脉络，削减数据搬运。

针对 RM-01 的 GPU、统一内存与多级缓存结构，我们量身打造 CUDA 算子，融合投影与相邻运算，并依矩阵规模动态择优计算路径。从权重加载、量化存储到运行时内存布局，层层压缩冗余分配与中间搬运，把宝贵带宽尽数留给模型计算。

持续 prefill，按需 decode。

引擎支持持续追加上下文，将输入消化与回答生成解耦调度。前缀缓存与递归状态管理复用前序计算，内存与 SSD 分层存储承接长程记忆——新消息、新文档与任务反馈源源不断进入，模型静默消化，只在需要发声时瞬间启动 decode。

这种机制赋予 Agent「边听边想」的能力，无需每次输入都仓促作答。无论是全程静听一场会议，还是增量研读陆续抵达的卷宗，模型都随信息流同步推演，在关键时刻精准介入判断与行动。

深度定制 vLLM

从底层算子到工具链，全栈深度调优。

围绕模型执行特征与 RM-01 硬件平台，我们完整移植并重写了核心 GPU 算子，攻克 PTX 与编译工具链的兼容壁垒，顺利完成 FlashInfer 推理内核库与 Transformers 5 的深度适配集成。

在 Fused MoE 内核调优中，我们打通了 Triton 工具链的兼容瓶颈，令内核参数得以紧贴具体模型与硬件特性精细寻优；同时对推测解码等关键路径实施专项定制，进一步推高推理吞吐。

专精 RMQ，亦向开源生态敞开大门。

定制 vLLM 在原生支撑 RMQ3x 与 RMQ4 的同时，也为 RM-01 运行各类适配开源模型筑牢底座。你可以随任务自由挑选模型，在同一台设备上灵活搭建多元的专业应用与 Agent 工作流。

从架构到训练，锻造专业能力。从硬件到推理，释放模型潜能。

RMQ3x 与 RMQ4 融汇递归记忆、注意力检索与定向后训练，锻造出扎实的专业洞察与工具执行力；自研推理引擎则紧贴架构与硬件，重塑计算路径、访存效率与并发调度，让这份智能真正扛起长文档研读、多轮推演与全天候运行的 Agent 重任。
