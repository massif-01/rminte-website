# RMinte 网站视觉规范

本文件是根目录 [DESIGN.md](../DESIGN.md) 的简版，纳入截至 2026-09-06 的已确认设计决定。旧预览只作为历史讨论材料；正式源码在当前站点目录，发布状态以实际部署核验为准。

## 核心原则

以真实产品影像、材料和工程细节呈现价值。界面采用黑、石墨灰、银白；不向照片或影片叠加品牌彩色光晕。首页自动播放入口、结构分解、宝石点亮和工艺切换保留。

## 共用规则

- 用户于 2026-09-06 确认：首页全部章节（包括“世界级制造”）与图册页面、影像容器背景使用纯黑 `#000000`。两页 HTML 根元素通过 `product-theme` 使用 `brand.css` 中的黑色背景变量。面板与控件保留必要层次。
- 指南、下载、OTA 与灯板工具保留较轻石墨灰：背景 `#141618`、次级背景／代码块 `#191c1f`、面板 `#1c1f22`、加强面板 `#24282c`。
- 主文字 `#e5e7e8`、正文 `#cbd0d4`、辅助文字 `#a9adb2`、次要信息 `#969da3`。指南正文直接落在背景上，不额外包裹大卡片。
- 颜色、字体和圆角集中在 `assets/brand.css`；首页与图册的纯黑主题不扩展至 OTA 与灯板工具。
- 首页界面背景与章节衔接使用纯黑；配色调整不改变媒体内部颜色，散热取景与渐显按下文执行，宝石光线不擅自调整。
- 白色 Logo 使用从原始矢量提取的 `assets/images/logo-white.svg`，保持比例。
- 首页左上角 Logo 在向下滚动的前 240px 内逐渐淡出，回到顶部恢复；完全隐藏后不接收点击和键盘焦点。其他菜单保持现有行为，图册与支持页 Logo 不变；减少动效模式下 Logo 保持可见。
- 字体沿用 Geist / Noto Sans SC，产品字标保留 Quantify RM。品牌名称 `RMinte AI` 整体使用 Quantify RM，包含其中的 `AI`；普通正文中的 AI 沿用界面字体。
- 桌面内容最大宽度 1280px；统一外边距 `--section-x`，手机为 24px。
- 支持页标题使用 `--page-title`，桌面最大 64px，手机通常 34px；子页面区块标题使用 `--page-section-title`。图册标题桌面 36px、820px 及以下 32px，简介 14px。
- 首页保留两档主区块标题，以已确认示范为准。指南正文使用 32 / 24 / 19 / 16px 标题层级；手机为 26 / 22 / 18 / 16px。
- 页面介绍 16px，移动端 15px；指南正文 16px / 15px，行高 1.9。
- 文字按钮与导航采用胶囊形（`--radius-button: 999px`），图册箭头与图标控件采用圆形；搜索框使用 32px 圆角。信息面板保持 8px，表格和文件标识保留 4px。主要行动使用银白底；次要行动使用深色底和细边框。
- 导航、页尾、语言按钮、焦点样式使用 `assets/styles.css` 中的共同规则。

窄屏（不超过 1120px）顶部语言与菜单按钮统一为 56 × 44px 胶囊，背景与边框一致；菜单图标居中。主站、下载、指南与图册的语言按钮统一显示目标语言名称：英文入口为「EN」，中文入口为「中文」。

界面中的方向箭头、关闭、播放、编辑操作等图标使用 SVG，统一采用 24 × 24 坐标系、1.6 线宽和圆角端点，并按按钮尺寸居中。不要用字体字符代替操作图标；正文标点、尺寸与数学符号、键盘说明及用户选择的 Emoji 素材保留原义。已有 Logo 和菜单线条沿用矢量或 CSS 实现。

## 页面分工

- 指南、下载与图册使用贴顶、通栏且具有不透明背景色的导航元素，背景直接设在导航上，下缘渐隐独立处理，不用页面伪元素代替导航背景；导航控件按 `safe-area-inset-top` 下移，横屏内容避开左右安全区域，避免滚动内容露到状态栏背后。
- 首页：保留视频、结构分解、散热图文渐显、宝石点亮及工艺切换；具体位置与比例按已确认规范执行。
- 蓝宝石底图与点亮层共同覆盖章节，保持相同取景并与点亮遮罩对齐；不再将图片元素整体缩小至 85%，避免手机右侧出现图片断边。
- 绒光玻璃保持既有图片缩放、位置和亮度，采用左侧 28% 渐隐接入黑色。连接接口保持取景，图片上下各 6% 渐隐，左侧过渡接入纯黑。换卡视频保留既有比例、位置和上下 8% 渐隐，外围过渡统一为纯黑；不为铺满章节而放大或裁掉展示重点。
- 图册：完整展示原始摄影，横竖图均不强制裁掉产品；保留按钮、键盘和滑动切换。
- 下载：分类索引、文件信息、主次行动清楚分层；保留原资源地址和文件。
- 指南入口：等权角色卡片、单独的网络专题、站内指南搜索。
- 指南正文：阅读宽度、目录、表格横向滚动、代码复制和提示内容优先。

`assets/brand.css` 是统一品牌变量与服务组件；`assets/styles.css` 是主站共用布局和首页样式；图册、下载、指南的专用布局分别放在各自 CSS 内。原 `detail-refinements.css` 已合并，避免覆盖文件继续累积。

`tools/emoji2pixel/` 灯板工具与 TianShanOS OTA 保留既有设计、合作方署名与许可，只有任务明确涉及时才修改。现有技术文案、参数、版权文字和下载材料不因视觉调整而改写。

## 推理引擎与整机协同

采用已确认的 A 版抽象磨砂方案：推理引擎使用三层平台图与三段可切换说明；整机协同桌面左文右图，手机重排模块与线路。沿用现有字体，RMinte 字标使用 Quantify RM。

模块默认模糊 2.5px，聚焦后清晰至 0px，过渡 450ms；减少动效关闭过渡。ESP32、W5500、交换机和 MAC/PHY 的抽象内部结构有区别；统一标注 ESP32，两台计算机及 ESP32 均有各自从属存储。图形不模拟真实裸片、封装引脚或 PCB 布局。应用侧独立存储位于 x86 左下方，连线从 x86 左侧折向存储；交换机说明贴近模块下缘，存储及其说明向上收紧。图内 CUDA／x86 字号为 16、计算机标签为 14、TianshanOS 为 17（手机为 20），均按图示坐标单位缩放；左侧章节标题不变。推理计算机、TianshanOS 与应用计算机标签到对应模块的可见间隙保持一致，桌面约 12、手机约 8 个图示坐标单位；按文字上下边缘衡量，不直接比较基线距离。

- 配置驱动硬件：仅 ESP32 清晰。
- 南北向设备控制：W5500、RTL8367RB、两侧 MAC/PHY 清晰，并强调它们与交换机的连线。
- 安全配置包：仅配置存储清晰。
- OTA 与自动化：仅 ESP32、W5500、RTL8367RB 及 ESP32 → W5500 → RTL8367RB 通路强调；两台计算机的 MAC/PHY 与支路保持默认暗态。

支持独立悬停、点击和键盘查看；切换主题清除手动查看状态。模块、文字与连线使用同一容器的归一化坐标，窗口缩放与断点切换后仍须对齐。每束三条路径贴合模块边缘，不以遮罩遮盖越界。完整布局与交互规则见根目录设计规范。

硬件架构的五张模块卡片不显示 01–05 装饰性小序号，也不为序号预留标题空隙。首页各章节标签仅保留中英文名称，不显示 01–10 序号及其斜线分隔符。

## 散热与工艺

叶片特写为缩小前尺寸的 70%，图片、横线与注释共用容器（最大宽度 296.8px），统一靠右，字号不变。761px 及以上对应右下旋风区域，完全显现时注释底部距场景下缘 32px；760px 及以下在正文后顺排，窄屏取景保留真实风扇。图文整体随滚动渐显并可回退，减少动效时完整可见。图片高度与具体断点参数见根目录设计规范。

首页制造精度章节保留向下滚动切换四组图文的方式，不增加点击或左右滑动切换。首页唯一页脚置于制造精度的粘性场景内，从第一组图文起随章节出现，不再等切换至最后一张；窄屏内容高于视口时允许自然滚动到完整落款，再保持其可见。右下方显示“向下滚动，查看更多工艺”（英文同步），最后一组隐藏提示，向上回滚恢复。减少动效或视口高度不足 740px 时沿用四组顺排，不显示切图提示。页脚细分隔线与联系交互保留。

首页工艺图文与内置页脚之间的间距为桌面 20px、窄屏 16px；场景本身不叠加底部留白，也不继承章节通用上下留白。

## 模型

模型页位于 `models/`，采用已确认的纯黑与银白，保留 Dense／MoE 动态示意、场景切换、评测粒子、引擎页签和技术折叠项，并支持减少动效。导航中的“模型”位于“图册”之后，中英文和移动菜单同步，语言选择与主站共用。未公布的评测保留预告，未配置的模型主页入口保持禁用。

## 图册、下载与指南

图册顶部标题、简介与 HDR 提示左对齐纵向排列。简介下方间隔 10px 放置银灰色 12px 提示与 Google Material Icons 的 HDR 矢量图标；图标使用银白色 `--ink`，正文使用灰色 `--dim`，垂直居中，不加光晕或闪烁。该标识说明图片支持 HDR，不表示当前设备已启用 HDR。中英文同步，手机自然换行。提示为“本图册支持 HDR 浏览，兼容设备可呈现更丰富的明暗细节。”

图册采用顶部标题与简介、居中完整摄影、底部单行图片说明与计数／翻页按钮的布局；手机将说明与翻页分行。移除图册内容区的装饰分隔线、重复编号、英文分类与分段进度条，保留 11 张照片、前后按钮、键盘及滑动切换。图册页底复用主站页脚、版权数据与联系脚本。

下载中心的分类入口、章节标题与发布条目不使用序号或重复的英文装饰标签；名称随中英文切换，依靠字号、留白和分隔线组织层级。文件格式、产品名称及版本信息保留。

指南入口不显示分组数量或卡片序号、英文装饰小标题，保留随语言切换的名称与章节信息。

## 页脚与联系面板

图册、下载、指南入口及指南正文与首页共用页脚：页脚上方内边距 24px、下方 40px；支持页正文末尾留白桌面 20px、窄屏 16px，不叠加章节级大间距。

主站八页统一显示 Logo、公司名称、「© 2026」版权信息、GitHub 与联系入口。双语文案复用 `assets/site-data.js`；支持页使用 `assets/footer.js`，首页使用 `assets/main.js`，并同步指南生成模板。

联系弹层采用单层石墨灰面板与细边框，标题只显示当前语言的“联系我们”；销售与渠道合作、制造与供应链合作、售前与售后服务三个邮箱按此顺序排列，使用细线分隔的文字入口及 SVG 斜箭头，不使用双层套框或大胶囊。关闭按钮为 44px 圆形，桌面弹层最大宽度 400px，手机两侧留白 16px。

## OTA 与灯板工具

- OTA：地址复制为主要行动，步骤与发布信息分层；实际升级在设备 WebUI 中执行，接口与发布资源保持独立。
- 灯板工具：桌面素材／画布／属性三栏，关键帧位于画布下方；平板切换侧栏，手机画布优先、标签切换面板。保留八种语言与原图形处理能力。
- OTA 在构建时从 `brand.css` 与白色 SVG 生成内嵌品牌资源。修改品牌基础后从仓库根运行 `node scripts/build-service-brand.mjs`；Wrangler 构建也会执行该命令。

OTA 展示文案中的 RMinte、RM-01 与 TianShanOS 使用现有 Quantify RM 专属字体；文件名、接口地址维持等宽字体。全站 GitHub 品牌入口使用用户提供的 GitHub 图标与矢量字标，按原始比例显示并继承按钮文字颜色；图标统一为 18px，字标为 42.25 × 13px，与相邻文字按钮保持视觉平衡。保留链接的可访问名称与中英文说明，指南生成模板保持同步。

OTA 与灯板工具的语言、菜单控件沿用主站 44px 高胶囊样式与双横线菜单图标；菜单和语言按钮宽 56px，灯板工具的八语言下拉框按语言名称适当加宽。

灯板工具围绕“选择素材 → 调整图形 → 下载或发送”组织。桌面分为素材、画布、当前编辑对象三区；常用移动与选择工具位于画布上方，位置与大小、选区操作、全局颜色处理与单帧覆盖分组表达作用范围。灯板参数通过矩阵摘要入口按需打开。平板与手机保留画布，切换素材、调整与动画面板；手机的切换栏随实际画布区域高度定位，避免长语言标签换行后互相遮挡。

普通素材选择替换当前图形，明确点击“添加一帧”后才追加；替换与删除可撤销。GIF 导入默认替换完整动画，追加模式则保留已有帧，入口就近说明。动画区域可折叠而不删除内容。底部输出区集中下载和发送，区分当前帧 PNG／复制图像、原始像素与灯珠效果预览、完整原始像素 GIF；发送面板先展示实际目标与内容，再提供确认发送及真实结果反馈。

灯板工具的按需面板使用独立 SVG 叉号关闭，不加圆形底框；保留 44px 点击区域、键盘焦点与 Escape 关闭，打开时焦点落在面板标题。文字操作按钮继续使用胶囊形。新增字段、状态和引导同步八语言，保留原作者、GitHub 与许可文件。
