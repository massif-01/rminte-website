# TianshanOS 0.6.4 界面演示

官网使用的纯静态模拟展示，无后端。页面结构与样式取自正式 [v0.6.4](https://github.com/RMinte-AI/TianshanOS/tree/v0.6.4/components/ts_webui/web)，提交为 `120f0c79b494ce683342471c2c11ed5458eb003a`，来源记录在 `source.json`。不复制固件的 API 客户端、WebSocket 或认证脚本。

设备面板以 2026-11-05 实际运行的 `0.6.4+9d5b0a00dd.11050027` 页面核对：保留原生服务卡片及状态灯、启动／停止／日志、GPU 显存环、温度和未绑定仪表，以及对应组件管理和运行记录布局。设备上观察到的是 `Qwen3.8-27B-NVFP4`；第二张 `Qwen3.8-Flash-Next-NVFP4` 为用户指定的演示卡片，默认停止。两张卡片独立模拟启停和日志，不代表硬件实际运行了两个模型。展示数据和标识已处理为本地示例，模拟说明位于界面下方。

图标沿用该版本的 Phosphor 矢量，保留站内已有的 [MIT 许可](../assets/icons/phosphor/LICENSE)。

## 结构与范围

- `index.html` 是桌面演示窗口；七个命名入口及 `ota.html` 保留实际静态页面，均直接返回 200。页面内使用 hash 导航。
- `assets/pages.js`：中英文的已渲染静态页面、页头和 TTI、曲线、组件管理、LED 设置、配置与备份、用户变量、运行记录弹窗。只保留已映射的点击标记，未实现的操作明确标为 `previewOnly()`；未知点击映射直接报错，不用通用提示掩盖接线错误。无用的原生输入事件、国际化与权限标记已移除。
- `assets/upstream.css`：0.6.4 原样式，仅将该版本的 Quantify Regular 字体引用改为演示目录内的 `assets/quantify-regular.woff2`。
- `assets/demo.js` 与 `demo.css`：单风扇、模拟数据与本地交互。只展示“风扇 0”，默认智能（TTI），标注推荐。曲线选择器也只有风扇 0。
- `assets/viewer.js` 与站内共用的 `../assets/tianshanos-demo-frame.mjs`：把真实页面放进固定 1440px 的 iframe，再按窗口等比缩放，保留设备面板与风扇同排的桌面布局。

可以体验模式切换、手动调速、编辑和保存示例曲线、TTI 说明、灯光色相／饱和度／亮度、网络分组、示例目录与文件、预设终端命令、规则启停／模拟执行、示例主机指令和 OTA 进度。停用规则或停止引擎后不会模拟执行，执行计数跨页面保持一致。其他设备操作明确提示仅供查看，不伪造成功；账号密码输入禁用，不生成可用凭据。关闭或重置演示后恢复英文与初始状态；演示不使用真实账号的本地存储。

所有数据均为示例；IP 使用 `192.0.2.x`，域名使用 `demo.invalid`。不会运行真实 TTI 模型，转速与预测读数也不证明设备性能。页面 CSP 设置 `connect-src 'none'` 和 `form-action 'none'`，不能连接设备、上传表单或请求升级服务器。

## 查看与维护

从仓库根运行静态文件服务，以 `website/` 为根，访问 `/tianshanos-demo/`，默认英文。可以在演示内主动切换中文，也可用 `?lang=zh` 直接核对中文。字体引用依赖站内目录，不再支持将文件夹单独搬离本站资源树。

首页与独立入口均使用同源的 1440px 桌面画布，每次打开默认英文，接收 `tianshanos-demo-height` 调整缩放后的高度；长内容由窗口滚动。手机保留电脑查看提示。内部弹窗和反馈按缩放后的可见范围定位，弹窗先响应 Escape，再按一次才关闭外层窗口。外窗标题的 TianshanOS 复用站内专属字体，语言切换后仍保留标记。

下次更新时从目标发布标签的干净源码启动本地模拟数据环境，核对并提取八个页面及关键弹窗的中英文已渲染结构（包括移至 body 的网络、SSH 弹窗与选中主机后的指令卡片），转换事件标记，并补齐通过脚本绑定的命令展开、关闭等事件，替换 `pages.js` 与原样式，同时更新 `source.json`。保留单风扇与本地模拟层，不从未提交工作区或真实设备拷贝凭据及状态。浏览器核对七页、OTA、关键交互、语言、窄屏和网络请求，再运行仓库字体与静态检查。
