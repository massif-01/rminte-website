# RMinte 网站视觉规范

基准：用户于 2026-09-05 确认的深色动态示范 `design-preview/v2/`。

## 核心原则

以真实产品影像、材料和工程细节呈现价值。界面采用黑、石墨灰、银白；不向照片或影片叠加品牌彩色光晕。首页自动播放入口、结构分解、宝石点亮和工艺切换保留。

## 共用规则

- 官网八页、OTA 与灯板工具统一采用较轻石墨灰：背景 `#141618`、次级背景／代码块 `#191c1f`、面板 `#1c1f22`、加强面板 `#24282c`。
- 主文字 `#e5e7e8`、正文 `#cbd0d4`、辅助文字 `#a9adb2`、次要信息 `#969da3`。指南正文直接落在背景上，不额外包裹大卡片。
- 用户追加确认 OTA 与灯板工具跟随主站最新配色。颜色、字体和圆角集中在 `assets/brand.css`，不再为主站与工具分别维护主题。
- 界面背景与章节衔接统一变亮，照片、视频、宝石滤镜及滚动逻辑保持原样，媒体内部的黑色不强制变灰。“硬件结构动态分解”章节及其影像容器明确使用纯黑 `#000000`，与黑底分解影像衔接；这是全站石墨灰背景的特定例外。
- 白色 Logo 使用从原始矢量提取的 `assets/images/logo-white.svg`，保持比例。
- 字体沿用 Geist / Noto Sans SC，产品字标保留 Quantify RM。
- 桌面内容最大宽度 1280px；统一外边距 `--section-x`，手机为 24px。
- 页面标题使用 `--page-title`，桌面最大 64px，手机通常 34px；子页面区块标题使用 `--page-section-title`。
- 首页保留两档主区块标题，以已确认示范为准。指南正文使用 32 / 24 / 19 / 16px 标题层级；手机为 26 / 22 / 18 / 16px。
- 页面介绍 16px，移动端 15px；指南正文 16px / 15px，行高 1.9。
- 文字按钮与导航采用胶囊形（`--radius-button: 999px`），图册箭头与图标控件采用圆形；搜索框使用 32px 圆角。信息面板保持 8px，表格和文件标识保留 4px。主要行动使用银白底；次要行动使用深色底和细边框。
- 导航、页尾、语言按钮、焦点样式使用 `assets/styles.css` 中的共同规则。

## 页面分工

- 首页：动效与产品叙述。主运行脚本中的媒体和滚动行为保持原样。
- 图册：完整展示原始摄影，横竖图均不强制裁掉产品；保留按钮、键盘和滑动切换。
- 下载：分类索引、文件信息、主次行动清楚分层；保留原资源地址和文件。
- 指南入口：等权角色卡片、单独的网络专题、站内指南搜索。
- 指南正文：阅读宽度、目录、表格横向滚动、代码复制和提示内容优先。

`assets/brand.css` 是统一品牌变量与服务组件；`assets/styles.css` 是主站共用布局和首页样式；图册、下载、指南的专用布局分别放在各自 CSS 内。原 `detail-refinements.css` 已合并，避免覆盖文件继续累积。

本次已纳入 `tools/emoji2pixel/` 灯板工具与 TianShanOS OTA 页面，保留合作方署名与许可。现有技术文案、参数、版权文字和下载材料不因视觉调整而改写。

## OTA 与灯板工具

- OTA：地址复制为主要行动，步骤与发布信息分层；实际升级在设备 WebUI 中执行，接口与发布资源保持独立。
- 灯板工具：桌面素材／画布／属性三栏，关键帧位于画布下方；平板切换侧栏，手机画布优先、标签切换面板。保留八种语言与原图形处理能力。
- OTA 在构建时从 `brand.css` 与白色 SVG 生成内嵌品牌资源。修改品牌基础后从仓库根运行 `node scripts/build-service-brand.mjs`；Wrangler 构建也会执行该命令。
