# RMinte 网站视觉规范

基准：用户于 2026-09-05 确认的深色动态示范 `design-preview/v2/`。

## 核心原则

以真实产品影像、材料和工程细节呈现价值。界面采用黑、石墨灰、银白；不向照片或影片叠加品牌彩色光晕。首页自动播放入口、结构分解、宝石点亮和工艺切换保留。

## 共用规则

- 基础背景 `#08090a`，面板 `#141517`，强调面板 `#1b1d20`。
- 主文字 `#f3f3f1`，说明 `#a0a2a4`，次要元信息 `#787c80`。重要正文避免使用最弱层级。
- 白色 Logo 使用从原始矢量提取的 `assets/images/logo-white.svg`，保持比例。
- 字体沿用 Geist / Noto Sans SC，产品字标保留 Quantify RM。
- 桌面内容最大宽度 1280px；统一外边距 `--section-x`，手机为 24px。
- 页面标题使用 `--page-title`，桌面最大 64px，手机通常 34px；子页面区块标题使用 `--page-section-title`。
- 首页保留两档主区块标题，以已确认示范为准。指南正文使用 32 / 24 / 19 / 16px 标题层级；手机为 26 / 22 / 18 / 16px。
- 页面介绍 16px，移动端 15px；指南正文 16px / 15px，行高 1.9。
- 文字按钮与导航采用胶囊形（`--radius-button: 999px`），图册箭头与图标控件采用圆形；搜索框使用 32px 圆角。信息面板保持 8px，表格和文件标识保留 4px。主要行动使用银白底；次要行动使用深色底和细边框。
- 导航、页尾、语言按钮、焦点样式使用 `assets/styles.css` 中的共同规则。

## 页面分工

- 首页：动效与产品叙述。主运行脚本中的媒体和滚动行为保持原样。
- 图册：完整展示原始摄影，横竖图均不强制裁掉产品；保留按钮、键盘和滑动切换。
- 下载：分类索引、文件信息、主次行动清楚分层；保留原资源地址和文件。
- 指南入口：等权角色卡片、单独的网络专题、站内指南搜索。
- 指南正文：阅读宽度、目录、表格横向滚动、代码复制和提示内容优先。

`assets/styles.css` 是共用基础和首页样式；图册、下载、指南的专用布局分别放在各自 CSS 内。原 `detail-refinements.css` 已合并，避免覆盖文件继续累积。

范围不包含 `tools/emoji2pixel/` 合作商工具。现有技术文案、参数、版权文字和下载材料不因视觉调整而改写。
