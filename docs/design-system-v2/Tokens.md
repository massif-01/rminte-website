机器可读版本见 [tokens.json](tokens.json)。画板：`boards/Spec.png`。状态：方向已确认，阶段 0–4 已实施并提交（本地）。令牌集中在 `website/assets/brand.css`（2026-10-05 起；OTA 与灯板工具直接复用，改后运行 `node scripts/build-service-brand.mjs`），迁移期的 `--lg-*` 桥接令牌已全部退役，`styles.css` 开头只留 `--chapter-title` 与 `--text-media`。页面主题 `product-theme`（首页、图册、模型：纯黑）与 `support-theme`（下载、指南、OTA、灯板工具：抬升黑）把品牌变量 `--bg`、`--panel`、`--ink`、`--line` 等指向色阶，也在 `brand.css`。

## 间距、圆角

间距以 4pt 为参考：4、8、12、16、24、32、48、64、96、128、192；它是软规则，没有做成令牌，现有页面里 18、22、36 等历史数值保持原样。圆角令牌：`--radius-control` 4、`--radius-panel` 8、`--radius-card` 16（大卡片与影像）、`--radius-button` 999（胶囊）。

## 动效

时长：120（按压）／240（悬停）／480（面板）／800（入场）／1200ms（数字计数）。缓动：settle `.32,.72,0,1`（已有，不变）、reveal `.16,1,.3,1`（新增，文字行遮罩上移）、exit `.4,0,1,1`（离场，时长取 60%）。令牌 `--dur-press`／`--dur-hover`／`--dur-panel`／`--dur-enter`／`--dur-count`、`--ease-settle`／`--ease-reveal`／`--ease-exit`、`--stagger`。悬停、按压、展开一律取这些档位；滚动叙事（分解、散热渐显）、蓝宝石点亮、整机协同连线与推理引擎示意图的切换、模型页玻璃层与 LED 波动循环保留各自调好的时长与曲线。编排：标题逐行 → 正文 → 行动，错峰 70ms，总长不超过 1.2s。`prefers-reduced-motion`：关闭位移与计数，仅保留 120ms 透明度变化，内容始终完整可见。

## 组件

- 按钮：48px 胶囊；主行动银白底深色字；悬停提亮到 `#FFFFFF`、位移 -1px、240ms；按压缩放 .98、120ms；焦点环 2px 蓝宝石 + 2px 黑隔离（对比度 ≥ 3:1）。
- 卡片：16px 圆角、n-2 底、1px 内描边、顶边 1px 高光线（两端渐隐，模拟机身倒角）；无阴影、无发光。
- 导航：六项，顺序不变：图册、模型、产品、架构、指南、下载；当前页灰底灰环（白 10% 底 + 1px `line-2` 环），不用彩色。
- 语言：六语言下拉，显示当前语言，不用国旗。
- 链接：悬停或聚焦时蓝宝石下划线从左向右展开，480ms，reveal 缓动（`.link-reveal`，永久下划线用 `.link-underline`；已用于联系面板的邮箱与讨论区入口、指南面包屑与章节标题锚点，OTA 页的版本信息与接口链接用永久下划线）。
- 图标：SVG、24 坐标系、1.6 线宽、圆角端点；不用字体字符代替操作图标。
