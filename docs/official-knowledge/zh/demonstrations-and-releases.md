# 官网演示与真实设备的区别

TianshanOS 官网界面演示基于 0.6.4，是无设备后端的静态模拟。图表、示例文件、终端命令、规则执行和 OTA 进度不能当作真实设备结果。Admin/Root 当前指南依据 0.6.4。案例演示和下载按案例授权；公开案例介绍不等于已获演示权限。

固件和 WebUI 下载入口以下载中心与 OTA 服务当前发布为准，不把文档编写版本当作已经发布的固件版本。
