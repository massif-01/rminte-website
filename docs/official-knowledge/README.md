## 后续回答如何使用

1. 按问题选择资料，引用原始官网来源并带上适用版本。Admin、Root 与安全页面指南的版本、日期从官网原文读取，中英文不一致或缺少标注时构建失败；指南的 source_commit 记录构建所用 Git 提交。网络配置与硬件安全由 Owner 确认为不随软件版本变更的通用资料。
2. 产品介绍中的性能、安全、耐候、功耗等为官网发布表述，本轮未做独立测试。保留配置、精度、模型和其他限定，不将最大值、不同配置数值或不同来源拼成一个配置。
3. 当前页面、当前申请表与对应版本操作指南优先于历史宣传册。旧型号、旧配置、性能表和当前描述有差异时并列说明来源，不能静默改写旧文或把旧表当成现售配置。
4. 示意图、模型场景、官网模拟演示与公开案例分别保留其性质。行业场景不等于客户项目；公开案例不等于已获取部署验收或客户数据；0.6.2 静态系统演示不等于真实设备状态。
5. 样机条款保持当前公开版本。申请是期望，不代表获批；库存、批复日期、整机价值、收款账户和实际借用资料必须通过实际申请及工作人员确认。没有收集任何申请人数据或银行配置。完整协议只有中文官方原文，英文重点提示和表单原文另存；Agent 可以解释或翻译，但必须说明译文身份。
6. `default_retrieval: false` 的 OCR 补充只用来定位 PDF 原页。未逐项核对的参数、表格、报道、证书字段不能直接用于答案。本轮已逐页概览两份宣传册，但没有独立核验其中媒体报道或证书的真实性、有效性和范围。
7. 企业信息仅限公开来源。未公开的注册资本、人员规模、收入、客户身份、采购价格、详细售后条款等不得推测；资料未提供时说明缺口并引导至对应联系渠道。
8. OTA 当前发布、软件版本、库存和联系方式都可能变化。需要“最新”状态时重新读取官方来源。当前快照不是永久实时数据。
