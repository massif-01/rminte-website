# 灯板工具交互预览

状态：第一阶段，等待用户审查。未替换正式工具，未提交或发布。

从仓库根目录运行 `python3 -m http.server 8879 --bind 127.0.0.1`，打开：
http://127.0.0.1:8879/design-preview/pixel-workbench/

预览仅引用正式站点的品牌基础 CSS、字体与 Logo；不加载正式工具的 JavaScript，不调用设备 API，不写入正式工具的存储。当前标签页关闭或刷新会重置演示内容。

## 审查路线

页面右上角的“查看演示状态”可以载入空白、单图、选区、多帧和输出五种状态。载入会替换演示内容，可以撤销。

1. 空白开始：直接导入图片，或从 Emoji 列表开始。
2. 连续选择不同 Emoji：保持单图，替换可撤销。
3. 点击“添加一帧”再选择素材：新增帧。取消新增不改变已有帧。
4. 移动与参数：拖动画布或调整缩放、位置、旋转。自动适配与重置入口保留。
5. 框选或按颜色选择：选区出现后，调整面板优先显示选区操作；取消选区返回图形参数。
6. 动画：选中帧、播放与暂停、修改停留时间与过渡帧数。折叠不会删除帧。
7. 输出：选择原始像素或效果图，下载当前帧 PNG；完整动画 GIF 明确为模拟。
8. 设备发送：只能模拟成功或连接失败；没有任何网络发送。
9. 切换 EN / 中文；缩小窗口检查面板切换及画布可见性。

## 需要确认的设计决定

- 默认素材选择替换当前图形；只有明确“添加一帧”才新增动画帧。
- 桌面三栏，平板单侧可切换面板，手机画布上方、操作面板下方。
- 选区操作优先呈现；完整灯板设置不占默认编辑面板。
- 动画按需展开；下载与发送集中到稳定输出区域。
- 预览方向确认后才修改正式工具与设计规范。

## 真实能力与模拟边界

已实现本地图片导入、24 个示例 Emoji 的搜索分类、素材替换、撤销、图形变换、矩形/按色选区、选区填色与清除、内部选区复制粘贴、帧切换、定时播放、简化淡入淡出过渡、PNG 下载、浏览器图像复制和双语界面。

这是信息架构与交互演示，不是正式处理引擎：

- 灯板固定 32 × 32，设置面板演示灯珠外观选择；物理尺寸和完整灯板参数尚未接入。
- 颜色处理采用简化算法；原有量化、锐化与动画插值仍需在确认后的正式实施中复用。
- 选区编辑存放在输出像素坐标，内部粘贴回到原位置；高级选区变换不是本预览的实现目标。
- GIF 导出和设备发送仅有模拟反馈；PNG 实际生成，但像素结果来自独立演示渲染。
- 此阶段只实现中英文；正式工具的八语言文件完全未改，其余六语言的新文案与溢出验收属于正式实施阶段。
- 署名与原项目入口保留；正式作者/许可文件未变更。

- 实际浏览器操作：空白入口、Emoji 替换不增加帧、撤销、真实拖动框选、填充选区、明确新增帧、演示状态切换。

- 控制台检查未发现错误或警告；JavaScript 语法检查通过；新增文件空白错误检查通过。

减少动效规则在源码中覆盖过渡；本轮没有切换系统减少动效设置，也没有进行真实设备、正式算法或其余六语言验证。这些项目不能视为已经验收。
