## A 版本轮调整

| 功能 | 清晰显示的模块 | 点亮的连线 |
| --- | --- | --- |
| 配置驱动硬件 | ESP32 | 无 |
| 南北向设备控制 | W5500、RTL8367RB、两侧 MAC/PHY | W5500 与交换机、两侧 MAC/PHY 与交换机 |
| 安全配置包 | 配置存储 | 无 |
| OTA 与自动化 | ESP32、W5500、RTL8367RB | ESP32 → W5500 → RTL8367RB |

OTA 下计算机两侧 MAC/PHY、PCIe 与网络支路均保持默认暗态。独立悬停或点击查看仍可用；切换功能会清除点击状态。中英文图中标签和可访问说明统一使用 ESP32，为后续型号升级保留空间。

ESP32 采用主核心与侧边单元，W5500 采用横向分层，交换机采用中央核心与两侧单元，MAC/PHY 采用不等宽窄条。内部仍为抽象结构，不表示真实芯片版图。

本轮复核：桌面 1280px 中英文、手机 390px 英文和 320px 中文；四主题的桌面与手机清晰模块集合一致，OTA 仅两束连线使用强调色。手机内部图形未越界，无页面横向溢出；语言切换、方向键及手动聚焦清理通过。
