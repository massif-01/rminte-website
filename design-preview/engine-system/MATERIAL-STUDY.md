# 磨砂材质样张

入口：[material-study.html](material-study.html)。2026-09-06 的独立讨论样张，尚未获准用于完整系统图。

范围：CUDA、x86、ESP32-S3 和独立存储。计算模块与存储展示横向连线，控制模块展示从外部进入的纵向线段；不表示完整硬件拓扑。

两个版本共用尺寸、布局、文字和接线。A 为原有抽象磨砂；B 为用户提供的参考插画中提取的芯片图像：CUDA 保留完整金色边框、框内深色基底与中央硅片；x86 保留绿色封装基板与银色顶盖。外围银色支架、内存颗粒和大 PCB 不纳入提取范围。ESP32-S3 与存储沿用抽象材质。

表面采用清晰边界、统一左上方光照和 2.5px 背景模糊；聚焦时在 450ms 内降至 0px，内部逐渐清晰，取消后恢复磨砂。文字一直清晰，切换 A/B 保留聚焦状态。名称有独立留白区域，无额外模拟引脚和噪点。连线依据模块实际边缘逐条生成，不平移整束路径，也不靠遮罩隐藏越界。芯片图像是参考插画素材，不是实物裸片验证资料。

支持中英文以及静态／聚焦两种状态。减少动效媒体查询关闭过渡。

验证：两版本在 1280×720 桌面和 390×844、320×820 窄屏检查，中英文无横向溢出或标签越界。聚焦后四层玻璃计算模糊均为 0px，取消后恢复 2.5px；过渡时读取到中间值。读取模块尺寸和六条路径确认端点贴合边界。版本切换、状态保留、语言切换和 Enter 操作通过。资源加载正常，JavaScript 语法检查通过。减少动效规则经源码检查，未切换系统动效偏好。
