# 样机借用

官网公开申请、独立样机后台和持久后端。界面来自已确认的 Claude 示范稿，生产代码不引用 `design-preview/` 或 `output/`。本模块没有自动邮件、邮箱验证码、电子签章、银行转账或自动扣费。

## 页面与账号

- 官网“联系我们”末尾是“样机借用 / 点此申请”，在当前页面打开申请窗口，不增加介绍页。表单使用独立 Shadow DOM，避免其样式影响首页、案例、下载或指南；`website/sample-loan/application.json` 是供窗口加载的静态片段数据，不是独立页面。
- 案例页真实登录区为有权账号显示“样机管理”，进入 `/sample-loan/#admin`；台账是 `#admin-machines`。
- 共用案例会话。有效主管理员自动有权；其他 `role=admin` 必须由主管理员在“权限与收款配置”中授权。普通用户、被停用、撤权及待修改初始密码的账号不能进入。写事务再次核对会话、角色和授权，公开申请无需账号。
- 申请未通过后，后台根据已保存的申请信息和最近一次人工填写的未通过原因生成通知邮件，提供收件人、主题和正文；拒绝完成时自动展示，之后可再次打开复制。此邮件不依赖协议 PDF 或收款配置，仍由工作人员人工发送。
- 后台仅中文。公开申请沿用站点六语言；合同原文及交付 PDF 保持中文。申请保存当时的固定条款、重点提示、实际展示语言及对应摘要。

## 必须保持的规则

1. 型号和 NO（产品编号）允许重复，只有 SN（机器序列号）按 NFC、大写键保持唯一，显示值保留登记内容；借出时锁定身份。初审只执行一次，批准与抢占、版本、事件及任务同事务提交。正常实际归还才释放占用；押金未退仍可单独跟进。丢失资产不可借，赔偿结案不伪造归还。
2. 申请天数须为1—30天的整数，只表示意愿；批复填具体日期，管理员批复日期不受该输入上限约束。发货前更正排期与发货后延期分开。发货后延期须满足原借期超过七日、至少提前七日申请且原截止前批准；拒绝不改原期，无三日宽限。
3. 初批冻结普通编辑中的整机价值、币种及报价。更正价值仅限未寄出、未收款且未核定费用；美元重新报价仅限未寄出、未收款。发货时冻结最终计费基数。每日 1% 的基数始终是整机价值，本系统不自动核定或扣取违约金。
4. 金额使用整数分字符串，计算用 BigInt；不能把分直接放入按元输入框。美元牌价按每 100 美元折合人民币、四位精度。押金美元美分为 `ceil(3_000_000 × 1_000_000 / rateUnits)`；结算折算按冻结报价作 half-up，并保留来源、目标和舍入差额。
5. 取消、拒绝及丢失结案后仍可登记迟到款及退款；部分退款不显示全退。异常实收实付保留原事实，必须核对；“核对待认领款项”不新增现金。账务冲销只纠正录入错误，不能撤销真实银行交易。原流水金额与凭证保留，`voided_by` 仅作为冲销关联和有效凭证唯一索引的投影；更正后可按原凭证登记正确流水，未冲销的重复凭证仍拒绝。结清要求最后一次核定确认完整、每个应收项目及应退/未分配额处理完且无待核对事项，并由员工明确确认；余额归零不会自动显示“已结清”。
6. 所有事实保存 UTC 毫秒 ISO 时间，显示北京时间及 UTC。`submittedAt` / `recordedAt` 来自服务器；员工核对的实际发生时间单独保存，不能晚于服务器现在。归还按实际到厂时间停表。退款五个工作日只按主管理员核对的工作日历计算，日历缺失或未覆盖时明确提示，不猜中国节假日。
7. 企业申请、后台保存草稿及批复/修订均须填写统一社会信用代码，空值或纯空白不能保存；个人不采集企业字段。修订不覆盖旧 PDF、旧照片或初次申请。主体名称或信用代码更正必须重新核验并确认仍是同一法律主体；更换主体另立申请。误归还更正若机器已分配给新单，必须拒绝，不抢新单资产。
8. 下载取指定 ready 版本的真实存档，不重新打印。下载无需先配置收款账户；正式邮件正文须核对当前合同版本、documentId 和有效收款配置。文件版本过时返回冲突，禁止把 R1 附件配 R2 正文；下载、复制不表示邮件已发送或送达。

## 历史借出登记

台账新增/编辑可选择“已借出（历史登记）”。提交到资产接口时 lifecycle 仍为 active，附带 `legacyLoan:{borrower,contact,lentAt,dueAt,notes}`；borrower 必填，其余选填，未知日期保存 null。lentAt 为过去的实际时间，dueAt 如填写且借出时间已知，不得早于 lentAt。recordedAt/updatedAt 使用服务器时间，独立于历史实际日期。

`0005_sample_legacy_loans.sql` 新增历史记录并迁移 sample_allocations，保留原在线占用。每条占用恰好引用 request_id 或 legacy_loan_id，asset_id 仍唯一；库存、选机及初审使用同一占用约束。借出锁定 NO/SN/型号，历史资料和备注可补充，不能通过普通资产编辑释放占用，也不伪造申请、协议或账务。

- `GET /api/sample-admin/assets/:assetId/legacy-loans`：历史记录。
- `POST .../legacy-loans/:id/return|loss|correct`：`{expectedAssetVersion,occurredAt,reason,holdReason?}`；归还/丢失需核实过去实际时间，更正误登记使用服务器时间。归还/更正释放该记录的占用；丢失同时将资产设为 lost，不恢复空闲。已结束记录不能释放后来借出的占用。可新增保留原因，已有原因必须原样保留；修改或解除需主管理员单独调用 preservation，实物归还不解除档案保留。
- `POST .../legacy-loans/:id/preservation`：仅主管理员，`{expectedAssetVersion,holdReason}`，null 解除保留。

上述接口复用样机授权、事务门槛、幂等和事件记录。列表直接显示历史来源、借用方和服务器校时后的剩余/逾期时间；缺日期明确显示待补录。最近一次记录处理满三年后清理已结束记录及对应含个人信息事件，进行中或设置保留原因的记录不清理；补录多年前归还不会立即丢失档案。线下押金等未结事项应填写保留原因，由主管理员核实解除。

四款型号名称统一为 `( 275 TOPS )` 等括号内留空格格式，modelKey 不变；固定条款使用新版本，旧快照/PDF/哈希保持原样。

## 本地运行与验收

需要项目声明的 Node 版本、`npm ci`，以及 Playwright Chromium。所有命令从仓库根目录执行：

```sh
npm run preview:sample-loan
npm run test:sample-loan
npm run test:sample-loan-pdf
npm run check:footer
python3 website/scripts/build-fonts.py --check
```

本地交互预览运行官网 `_worker.js` 与静态资源、隔离 D1/R2 及实际 PDF 消费逻辑；网页与消费者使用同一个 Wrangler 运行时的绑定，不能再启动第二个 `getPlatformProxy` 同时打开该目录。已通过双进程写入复现提交标记内部错误和 SQLite 锁竞争，单运行时对照无错；修复在本地运行器的资源归属，不增加业务重试。预览使用本地 Chromium，**不是云端 Browser Run 验证**。终端仅输出临时账号文件路径，账号与数据均为隔离合成数据，进程退出后删除。浏览器 CI 仍使用真正的 `wrangler pages dev` 单独验证 Pages，PDF 管线另行验收；交互预览不能替代 Pages 与云端绑定验收。普通持久本地开发仍可使用 `services/case-access/wrangler.jsonc`，不得将生产数据库用于测试。

- API 集成验证覆盖权限/撤权、重复编号和请求、同台抢占、取消后迟到款、部分退款、故障回滚、调休日期及到期清理/争议保留。
- PDF 集成验证实际生成含照片的多页文档，检查旧文件不变、晚到租约不覆写、版本绑定正文、归还释放、重新分配后拒绝误撤销，以及丢失后的押金抵扣、补偿与结案。
- 浏览器还需按仓库规则检查真实入口、校验、全部业务交互、1440/768/390/320、键盘与 Safari 输入方式。只通过 Node 测试不能代替界面验收。

测试状态以当次执行结果为准；此文不是部署证明。现有 CI 增加样机依赖识别、实际 D1 测试及实际 Chromium PDF 验证，不放宽案例或既有页面检查。

## PDF 与文件

协议正文按申请时的界面语言选择：中文使用中文，其余语言统一使用英文。申请前预览采用同一规则；申请确认记录与每次批复快照保存 `agreementLanguage`，后台预览和 PDF 均读取快照，不受管理员界面语言影响。`RM01-LOAN-20261106-r7` 新增完整英文条款，中文正文不变；条款及译文一并归档并计入摘要。没有该语言记录的历史申请继续使用原中文版，已有 PDF 不重写。

发布此项变更时，先更新 PDF 任务 Worker，再更新官网 Pages。旧 Worker 会忽略新申请的 `agreementLanguage` 并生成中文版，因此不能只发布主站；新版 Worker 对无语言字段的旧快照仍按中文处理。两者发布后，分别核对提交版本，并以非中文申请的实际预览及存档下载验收。

英文使用 equipment loan、security deposit、liquidated damages 和 declared-value coverage，保留原有中国法律适用及管辖约定。姓名、法律主体名称、地址、设备账户和管理员填写的交付事实原样保留，不自动翻译。`SAMPLE_PDF_LANGUAGE=ja npm run test:sample-loan-pdf` 可验证非中文申请经实际审批生成英文 PDF；默认命令验证中文版。

PDF 使用独立固定来源的 Noto Sans SC，以及只补缺字的 Noto Sans JP 回退；字体许可和每个文件摘要保存在 `document-assets/`。不会改用本机字体，原网页小子集仍只服务界面。重建文档资源：

```sh
python3 services/sample-loan/build-document-assets.py
```

生成前逐字段检查字形；确实不支持时定位字段及字符，不删字或输出方框。等待字体与图片完成解码；每页有 30mm Logo 页眉和一枚稀疏、4.5% 不透明度的斜水印。先排版再计算最终 PDF 的 SHA-256。每次尝试使用独立对象 key，只有当前租约能发布；旧消费者不能覆盖胜者。

上传不设业务上的图片数量或整图大小上限，采用每片最多 8MiB 的续传。服务器流式计算原图摘要，可额外比对客户端摘要；multipart ETag 不当作 SHA-256。PDF 图片衍生物每张不超过 **500,000 字节**，原图另外保存。添加或移除后须保存草稿/修订才成为对应版本的附件清单。

平台并非无限资源：当前消费者不自动解码超过 64MiB 的单张原图，上传原件仍保留；这只是处理保护值，不是该范围在免费云环境中都能成功的承诺。超限、压缩预算无法处理或字体缺字时须报错或进入人工处理，不能删图假装完成。SN 等细节的可读性由管理员复核，需要时补拍局部照片，不声称自动完成 OCR 检查。进程超时/资源终止也受租约及最多五次尝试控制。真实云端的最大合理附件样本、CPU、内存、浏览器时间和免费额度仍须在隔离环境实测；本地成功不代表可无限免费生成任意大小的 PDF。

## 云端接入与发布边界

本地配置与真实云账号开通状态分开。此实现不自动购买、创建生产资源或部署。

| 消费者 | 必要绑定/设置 |
| --- | --- |
| 官网 Pages | 现有 `CASE_DB`、`CASE_SECRET`；新增私有 `SAMPLE_FILES`、队列生产者 `SAMPLE_JOBS`、独立随机 `SAMPLE_SECRET`（至少 32 字节的 base64）；`nodejs_compat` |
| 独立任务 Worker | 与 Pages 同一环境的 `CASE_DB`、`SAMPLE_FILES`、`SAMPLE_SECRET`；`BROWSER`、`DOCUMENT_ASSETS`、队列生产/消费及五分钟 Scheduled Trigger |
| 管理员配置 | 真实台账、主管理员核对的人民币/美元收款信息、工作日历及必要的样机授权 |

`wrangler.jsonc` 只声明本地资源名和占位数据库 ID；执行前按实际账号配置独立生产/Preview 资源，不能直接把本地占位当生产配置。任务 Worker 关闭 workers.dev、预览 URL 和公开路由，HTTP 入口返回 404，不能把照片或合同放进公开 assets。Secrets 不写进仓库。

Pages 的 Git 构建使用仓库锁定的 Wrangler 预先打包，并输出为 ES2020；平台内置的 Wrangler 3 不支持源码中的 JSON 导入属性，且会错误转换预打包代码的类静态块。构建命令为：

```sh
./node_modules/.bin/wrangler pages functions build --project-directory . --build-output-directory website --outdir /tmp/rminte-pages-worker --compatibility-date 2026-10-26 --compatibility-flags nodejs_compat && ./node_modules/.bin/esbuild /tmp/rminte-pages-worker/_worker.js --target=es2020 --format=esm --outfile=website/_worker.js
```

更新 Pages 配置时，不得把 GET 返回的 Secret 空值占位写回；只提交需要变更的变量，保留既有 `CASE_SECRET`。新密钥必须在发布前存入受限备份。

后续获得发布授权时：先确认备份和环境隔离，通过 `wrangler d1 migrations apply` 按顺序应用未执行的迁移，核对 Pages 绑定/兼容标记及任务 Worker/队列/定时任务，再上线和逐一验证真实版本。Owner 合并带来的自动上线仍遵守仓库原规则；不要顺带发布 OTA。

`0007_sample_no_repeat.sql` 纠正 NO 的唯一限制，保留全部资产字段、ID 及外键关联，SN 仍唯一；保留 `no_key` 列以兼容已部署的读写接口。应用前备份 D1，应用后核对台账和关联记录及外键检查结果，不修改机器实际编号。

该迁移须整文件执行，确保父表重建处于同一事务；不要拆成独立请求逐条执行，`defer_foreign_keys` 不跨事务保留。已应用的迁移不重放、不改写执行内容。代码回滚可保留当前数据库结构；不要随代码回滚恢复 NO 唯一约束。若确需恢复该约束，必须先经业务确认处理已存在的重复 NO，不自动删除、改号或合并样机记录。

`GET /api/sample-admin/health` 检查绑定、最老待办、失败数和最近成功补查时间。任务未入队、消息过期、消费者中断均由 D1 待办恢复。租约修复后，队列投递与资料维护分别执行；任一失败仍使当轮调度报错，最近成功补查时间只在整轮成功后更新。资料清理失败不能吞成成功。

## 保留、清理与恢复

未实际出借的已关闭申请满 90 日，已出借业务在实物结束且费用结清后满三年，才可进入清理。争议/法定保留与未结款阻止清理；主管理员可在清理开始前设置保留。清理先停止任务并留一天宽限，正式开始后阻止恢复和业务写入，再移除请求相关私有对象及数据库关系；编号不复用。孤立 PDF 每日按引用和租约检查、宽限后删除，已发布文件不删除。

样机安全记录（写操作、鉴权拒绝与文件访问请求）独立保存六个月，不记录请求正文、默认账户或密码。该规则不追溯修改案例系统原有登录日志。

D1 与 R2 必须做关联备份，恢复后核对授权、原始申请、台账/占用、版本、文件摘要、金额投影和待办。恢复期间暂停任务及清理，完成关联核对后再启用，避免把尚未恢复的文件引用当成孤立对象。法规或财务档案要求更长保留时，应由主管理员设置对应保留并按实际制度管理，不把一般三年规则当统一法定期限。

## 依赖安全说明

`package.json` 对两个实际存在的传递依赖使用定点覆盖，并由锁文件固定：Miniflare 的 `undici` → `7.30.1`，`get-uri` 的 `basic-ftp` → `6.2.3`。前者修复 EventSource、完整性校验与内容编码相关告警；后者修复 FTP 列表解析等问题。FTP 6.x 默认不允许独立传输主机，项目没有 FTP 业务，也没有启用旧行为。Wrangler 4.152.0 仍声明旧 Undici，单升 Wrangler 不能解决该告警，不为此引入无关升级。

为兼容 CI 的 npm 10，Undici 按依赖名覆盖（目前唯一调用链是 Miniflare），FTP 保留 `get-uri` 作用域；npm 10.9.9 与 npm 11.6.0 的隔离干净 `npm ci` 均验证实际只安装 Undici 7.30.1 和 FTP 6.2.3，不能用重新装回旧版来满足锁文件。

2026-10-26 的审计由 10 项降至 3 项高危：均属于 `@cloudflare/puppeteer → @puppeteer/browsers → extract-zip` 的同一传递链，根包 `extract-zip@2.0.1` 有两项符号链接路径穿越公告，尚无修复版本。保留真实告警，不强降官方 Puppeteer、不替换空包、不放宽审计门槛。项目不使用该包的浏览器下载/解压功能；PDF Worker dry-run 的构建元数据证实 `extract-zip`、`basic-ftp`、`undici` 均未进入输入图或最终代码。此结论限于当前入口；以后引入 Node 浏览器安装、ZIP 解压或变更打包方式时必须重新评估。

API、Pages 浏览器、真实 PDF 和配置构建已在修复后重跑；它们不证明真实 Cloudflare 套餐、队列、D1/R2 与 Browser Run 已验收。
